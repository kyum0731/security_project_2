# 지원 범위와 제한

이 분석기는 저장된 Python 소스의 구문과 제한된 이름 해석을 기록합니다. 코드를 실행하지 않으며 완전한 호출 그래프나 실행 추적을 생성하지 않습니다.

## 연결할 수 있는 범위

같은 모듈의 유일한 직접 정의, 모듈 수준 함수의 재귀, 명시적인 import·별칭·상대 import, 명시된 모듈 멤버 호출을 이름 가림 검사 후 연결합니다. 클래스 생성 표현식은 클래스 노드에 연결합니다. 객체를 생성한 뒤 변수로 전달되는 타입은 전파하지 않습니다.

매개변수·대입·삭제·반복문·with·except·패턴·lambda·comprehension의 이름 가림을 보수적으로 취급합니다. 재대입이 범위 내 한 번이라도 있으면 호출 시점과 무관하게 미해결일 수 있습니다. 함수 정의의 기본값·데코레이터·클래스 기반식은 바깥 실행 범위에 속하며 타입 힌트 호출은 annotation으로 구분합니다.

## 미해결로 남기는 경우

- `self.method()`, `obj.method()`, `super().method()` 등 객체 타입·상속을 알아야 하는 호출.
- 매개변수 함수, 함수 값의 대입 전파, closure·global·nonlocal을 통한 값 전달.
- 재수출, wildcard import, 데코레이터로 의미가 바뀔 수 있는 정의, 중복·조건부 정의.
- 동적 import, monkey patch, import hook, sys.path 변경, metaclass의 실행 효과.
- namespace package 및 다중 소스 루트의 완전한 해석.
- 설치 환경에 따른 라이브러리 심볼·실제 가용성, 일반 참조와 런타임 흐름.

정적 규칙은 일반 Python 프로그램 전체에 대한 완전성·건전성을 보장하지 않습니다. 지원 규칙으로 연결된 관계도 런타임에 같은 대상이 실행됨을 보장하지 않습니다. 분기 도달 가능성·반복 횟수·타입 힌트 평가 여부는 계산하지 않습니다.

`external`은 명시적 import가 분석 인덱스 밖의 이름이라는 분류입니다. 잘못된 소스 루트 또는 범위 밖 내부 코드일 수도 있습니다. 알려진 제외 파일·내부 패키지의 빠진 하위 모듈은 module_not_indexed로 남깁니다. import 루트는 최상위 패키지의 부모로 선택하세요.

내장 함수는 실행 중인 분석기 Python의 내장 이름을 기준으로 판별합니다. 이름 가림을 검사하지만 런타임에 내장 객체를 교체하는 효과는 모델링하지 않습니다.

## 입력과 출력

`.py`만 읽고 `.pyi`·노트북·다른 언어는 분석하지 않습니다. 소스 루트와 제외 패턴은 보고서에 기록합니다. 링크와 junction을 따라가지 않으며 제외 디렉터리 내부 파일 수를 추정하지 않습니다. `.gitignore`는 자동 해석하지 않습니다.

파일별 읽기·인코딩·파싱 오류를 격리합니다. 분석 중 변경은 해시 재확인으로 진단하지만, 재확인 직후 파일이 바뀌는 경우까지 막지는 못합니다. 분석된 내용은 그 실행이 읽은 자료를 뜻합니다.

HTML은 외부 서버나 스크립트 없이 동작합니다. 읽기 안내에서 대상을 클릭하면 파일 상세의 앵커로 이동합니다. 일부 브라우저에서 접힌 영역으로의 앵커 이동이 자동으로 펼쳐지지 않으면 파일·코드 상세에서 해당 파일을 직접 펼치세요. 대규모 보고서는 브라우저 메모리와 표시 시간이 커질 수 있습니다.

업무 목적·정확한 입력 및 반환 값·오류나 취약점·완전한 변경 영향을 판정하지 않습니다. 작성자의 docstring도 실제 구현과 다를 수 있습니다. 후속 그래프·VS Code·Git·AI 기능은 현재 CLI의 옵션이 아닙니다.
